Accessibility

Here you'll find my accessibility statement: what useful features this website has, what I'm yet to implement, and how you can give me feedback/suggestions.

Table Of Contents
  • Implemented Features
  • Planned Features
  • Suggestions

Implemented Features

  • Alt text for images
  • Appropriate color contrast and minimal color palette
  • Back to the top and skip to content links
  • CSS sizing using em instead of pixels
  • Each link's text being specific, not general like 'click here', and external link indicators
  • Labels for forms: code-side and browser-side
  • Language attributes for each page within the html
  • Lazy loading images
  • No Javascript, only css, html, and some php
  • Providing multiple file formats of each image to speed up loading times
  • Section breaks announced with a hr
  • Semantic html: a header, nav, main, various sections for each subheading, and footer
  • System fonts so no loading remote fonts
  • Tables of contents on each page and post

Planned Features

  • Aria labels
  • High-contrast mode
  • Focus styles
  • Reduced motion options
  • WCAG level

Suggestions

Always open to hearing from folks on how I could improve! Please contact me with feedback or questions! You'll be credited here, of course.
