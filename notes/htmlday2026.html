HTML Day 2026 Is This Saturday

Come write HTML with me this Saturday.

HTML Day is an annual celebration of getting together and writing HTML, created by Elliott Cost and Laurel Schwulst. Saturday, August 8, 2026, is this year's date, and I'm running two online sessions again, same as last year.

Sessions

Two one-hour sessions, so folks across time zones can join in.

  • Oceania Time — 6-7pm AEST
  • European Time — 6-7pm CET

The European session also works out to 9-10am PT, 11am-12pm CT, and 12-1pm ET, if you're in North America.

No RSVP or signup required this year. I'll post the Google Meet link straight on the event page an hour before each session starts, so just turn up. Some experience with HTML helps, and you'll want a place to write it, but there's no pressure to publish anything you make. CSS is welcome too.

More Details

All the details, past guestbook entries, and HTML resources live on the HTML Day event page, which I keep updated year to year.

Hope to see you there.
